# PP Kyoto Font Files

Place your PP Kyoto font files in this folder.

Recommended filenames:
- `PPKyoto-Regular.woff2` (or `.woff` / `.otf`)
- `PPKyoto-Medium.woff2` (or `.woff` / `.otf`)
- `PPKyoto-Bold.woff2` (or `.woff` / `.otf`)
- `PPKyoto-Italic.woff2` (or `.woff` / `.otf`)

Once downloaded from Pangram Pangram (https://pangrampangram.com/products/kyoto), extract and drop the font files here.
